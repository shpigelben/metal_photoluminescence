# Contribution of Interband Transitions to Non-equilibrium Emission in Metals

![[C - previous_pdf.pdf]]

Internal project report (Ben-Gurion University of the Negev) summarising prior work on interband contributions to metal PL. Establishes the interband emission framework — including the k-space integral structure and the Rosei band model — that is extended and refined in the current project.

**Relevance:** The direct predecessor to this project. The current vault notes represent the continuation and revision of the analysis in this report.
